Scans ~/.claude/plugins/ for installed plugin manifests.

The AI Catalogue populates from a live scan of the local ~/.claude/ environment. This public demo renders committed fixture data only, so the catalogue stays empty by design (privacy leak-guard — ADR-0106). Install Tandem to see yours.
